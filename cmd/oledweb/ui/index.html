屏幕显示逻辑 每 950 ms 采样一次，按负载自动切换模式

1 行 · 空闲
居中显示 IP
CPU、温度、网速均未超过阈值
2 行 · CPU 高负载
CPU: xx% xx°C / IP
CPU 或 温度 超过阈值，流量不高
2 行 · 网络高负载
NET: ↓xx ↑xx / IP
RX 或 TX 超过阈值，CPU/温度正常
3 行 · 双重高负载
CPU / NET / IP
CPU 或温度 与 流量 同时超阈值
· 判断依据：CPU 占用 > CPU 阈值 或 温度 > 温度阈值 视为 CPU 高负载；RX 或 TX > 网速阈值 视为网络高负载。
· 阈值即上方三项可调参数；调整后约 1 秒内生效，无需重启服务。
· 防抖：新模式需连续 3 次采样都命中才切换，条件消失后立即回落到空闲模式，避免屏幕频繁闪烁。
· 平滑：网速采用 EMA（α=0.30）平滑，CPU 与温度取 1 秒粒度实时值；IP 每 5 次采样刷新一次，网络中断时保留上次地址。
